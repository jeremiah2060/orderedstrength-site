Design notes

How this site looks and why.

The colours, type sizes, spacing, and the reasoning that produced each of them. A reference for anyone building something that needs to match.

Thesis

This product is a measuring instrument that shows its receipts, so the page is the front panel of one. Machined surfaces under one light, a numbered specification, a scale down the side. Not a fitness brochure.

Signal discipline is unchanged and is the brand: teal marks verified state, current position, and one word per screen. Amber marks a broken seal. Nothing else is coloured. The ink and signal values are the app's own design tokens byte for byte, so the site and the app still read as one object.

Colour

The neutral ramp is an elevation ladder: each rung is measurably lighter and very slightly cooler, because ambient light in a real room is cool and a surface that catches more of it shifts with it. That physical fact is what separates a page that feels like a lit space from one that feels like grey rectangles on black.

Contrast of every ink-on-surface pair is checked by tools/contrast-gate.py on every deploy, not by eye. The check uses WCAG 2.1 AA as its floor and the token values themselves as its inputs, so a token change that drops a pair below 4.5:1 exits the gate immediately.

One light

Every raised edge on this page agrees about where the light comes from: above and to the left, cool, as an overcast window is. The lit edge is warm because a key light is warm. The shaded edge is a real dark line, not an absence, because a surface turning away from the light goes darker than the surface it sits on. Almost every dark interface draws one symmetric grey hairline and stops there, and that is precisely why they read as diagrams rather than objects.

Design principles

Signal discipline is the brand. Teal means one thing everywhere: verified, current, confirmed. Amber means one thing: a broken seal or a warning. Nothing else is coloured. A page that uses colour for decoration does not have a design; it has decoration.

An edge that lines up with nothing reads as an accident, even when someone chose it. Every pixel on this page refers to something else. The bar's left edge, the section heading's left edge, and the scale tick's left edge are the same line.

Motion has two jobs and they need different curves. Something arriving settles like mass (--ease). Something you touched answers with a little overshoot, because that is what a real control does (--spring).

The grain is a dither before it is a look. Dark radial gradients in 8 bits band into visible concentric rings on OLED and wide-gamut panels. Per-pixel noise breaks the quantisation, which is the same fix film uses. It rides on the background layers only, never across the text.

Contrast is checked by the machine, not the eye. WCAG 2.1 AA is the floor. Every ink-on-surface pair is measured on every deploy from the CSS token values. A token change that drops any pair below 4.5:1 fails the gate before it reaches production.
